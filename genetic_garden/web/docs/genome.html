Genomes

A project id becomes a plant, and the same plant every time. Everything downstream is a pure function of this.

source: genetic_garden/genome.py · every figure on this page is drawn by the code it describes

1An id, hashed

A genome has to be stable. A project that grew a particular crooked little tree yesterday has to grow the same crooked little tree today, on a different machine, after a rebuild. So the seed comes from the project's id and nothing else.

Python's built-in hash() is salted per process and will happily give you a different answer on the next run, which would quietly reshuffle an entire garden between deploys. blake2b does not.

def stable_seed(identifier: str) -> int:
    digest = hashlib.blake2b(identifier.encode("utf-8"),
                             digest_size=8).digest()
    return int.from_bytes(digest, "big")

2Genes know nothing about plants

A genome is a plain dict of 36 floats in [0, 1]. Not one of them is an angle, a length or a colour. Nothing in the chromosome knows what a branch is.

Expression happens separately, in traits(), which maps each gene through a range that depends on the kingdom. The same gene value means a different branch angle for a bush than for a tree, because a bush's range starts wider.

3Why that separation earns its keep

Splitting the chromosome from its expression buys two things that would otherwise need defensive code everywhere:

  • Breeding is always valid. Crossover and mutation operate on numbers in [0, 1] and clamp there. There is no combination of genes that produces a branch angle of four radians or a negative leaf.
  • A genome can change kingdom. Read the same chromosome as a tree and as a flower and you get two plants with a visible family resemblance — the same lean, the same branch rhythm, the same hue shift — expressed through different ranges. The studio's kingdom buttons do exactly this.
a consequence worth knowing

Genes are drawn in sorted name order, so adding a gene shifts every existing genome. That is fine while the gene table is still moving, but if you need plants to outlive a change, persist them with Genome.to_json() and load them back with --genome-file.

4Crossover and mutation

Crossover blends each gene by a random amount rather than picking one parent's value: a child of a columnar tree and a spreading one is genuinely intermediate, not one or the other. Mutation nudges a fraction of the genes by a gaussian and clamps the result.

5Small nudges, large plants

This is the part that makes the whole scheme worth having. Most genes do not feed a single feature — they feed a recursive rule. Branch angle, length ratio, curvature and habit are all applied once per level of depth, and depth increases as the plant grows.

So a 0.05 nudge is nearly invisible on a seedling and obvious on a mature plant. Siblings start alike and grow apart, with nothing in the code special-casing age.

6Habit: the one gene that matters most

If you only change one gene to tell two plants apart, change form. It is applied in _form_traits rather than in the range tables, because it scales several traits at once — it describes a habit, not a measurement.

formtreebush
0.0columnar: narrow angles, strong phototropismupright: tall, narrow fan
1.0spreading: wide angles, drooping limbsmounding: low, wide fan

Because every trait it touches feeds the recursion, a small shift in form is barely visible on a sapling and produces a completely different silhouette on a mature plant.
